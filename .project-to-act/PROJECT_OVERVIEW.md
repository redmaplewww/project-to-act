## 范围

### 包含

- v2 Skill 指令、五份模板、内容职责契约、配置迁移、审计、严格门禁、整理和恢复命令。

## 技术路线与关键约束

- 五份主文档继续作为活动状态视图；历史进入按职责和月份分区的 Markdown 归档。
- schema v1 保持可读，只有显式迁移到 v2 后才能整理。
- 整理必须先预览；归档先写入，源文件哈希复核后原子替换，并提供恢复清单。
